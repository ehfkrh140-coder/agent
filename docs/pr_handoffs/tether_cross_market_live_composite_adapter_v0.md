## 1. Purpose

Add a public read-only live composite adapter for the experimental, non-active `tether_cross_market_premium / usdt_krw_global_reference_v0` strategy. The adapter combines Upbit and Bithumb public USDT/KRW domestic observations with Binance, Bybit, and OKX public global USDT reference observations, then feeds the existing tether replay packet-builder path.
